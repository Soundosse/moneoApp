## 📱 About

**Moneo** is an intelligent mobile financial assistant designed primarily for students.

It helps users manage personal finances, shared expenses with roommates, budgets, recurring expenses and savings goals, while using AI to analyze spending habits, predict future expenses and provide personalized financial recommendations.

## ✨ Features

- 💳 Personal income & expense management
- 🏠 Shared expenses & roommate management
- 💰 Budget management
- 🎯 Savings goals
- 🔄 Recurring expenses
- 📊 Financial analytics
- 🤖 AI-powered expense classification
- 🔮 Spending forecasting
- 🚨 Anomaly detection
- 💡 Personalized recommendations
- 💬 AI financial assistant — Ask Moneo
- ✈️ Financial travel planning
- 🔍 What-if financial simulations
- 💸 "Can I afford it?" analysis

## 🛠️ Tech Stack

- **Mobile:** Flutter / Dart
- **UI:** Material 3
- **State Management:** Riverpod
- **Authentication:** Firebase Authentication
- **Database:** Cloud Firestore
- **Notifications:** Firebase Cloud Messaging
- **Backend:** Python / FastAPI
- **Machine Learning:** Pandas, NumPy, Scikit-learn
- **Deep Learning:** PyTorch
- **AI:** LLM + AI Agent + Tools
- **Version Control:** Git / GitHub
